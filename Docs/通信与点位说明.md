# 通信与点位说明

核对日期：2026-10-13。以下均为当前驱动的真实读写行为，不将地址常量中未使用的点等同于已实现功能。

## 1. 驱动选择、端口和站号

源码：[DriverFactory](../src/AutomatedLine.Infrastructure/Drivers/DriverFactory.cs)。IP 来自数据库；Protocol/Port 虽可保存，工厂不使用它们切换驱动。

| 资源 | 协议 | 实际端口 | 实际站号 |
|---|---|---:|---|
| 天车 | 汇川 Modbus TCP | 502 | 1 |
| 双头镗 | Modbus TCP | 502 | 1 |
| 研磨机 | Modbus TCP | 502 | IP 末段；解析失败为 1 |
| 打号机 | Modbus TCP | 502 | 1 |
| 上/下料架 | Modbus TCP | 10000 | 254 |
| 斜床 | FANUC FOCAS | 8193 | 无 Modbus 站号 |
| 动平衡、验点、货叉等 | 尚无真实驱动 | — | — |

同 IP 的上下料架目前仍各创建一个 ModbusDeviceDriver/连接，没有按 IP 合并通道。

料架原始允许信号按现场协议：上料架DI1/10001/PDU0，1有板允许取料、0无板不可取；下料架DI3/10003/PDU2，1无板允许放板、0有板不可放，DI2不参与。两者分别单点FC02读取，下料架经点位InvertDiscreteInput反转后发布HasMaterial，缓存/候选/放料等待/页面继续保持“true有料、false无料”的统一语义。通信失败不执行反转、不返回无板；完整地址见[料架点位](设备寄存器地址/料架地址.md)。

双头镗FC03逐点采集12203/12207/12215三个请求输入，FC06写12205/12213/12221三个输出。三参数301/303/309均为16位Word：长度/堵厚Convert.ToInt32原值，外径Convert.ToInt32(原值×10)，再转ushort；不写浮点/双Word或FC16。界面double原值保留，只有外径表达一位小数，.5按Convert.ToInt32取偶数。日志列原始值、地址、倍率和最终Word；其他设备沿用原Math.Round及点位倍率。详见[双头镗协议](设备寄存器地址/双头镗地址.md)。

## 2. Modbus 请求和异常分类

源码：[ModbusTcpClient](../src/AutomatedLine.Infrastructure/Communication/ModbusTcpClient.cs)。每连接通过 SemaphoreSlim 串行请求。设备驱动使用 App.Collection.CommunicationTimeoutMs（非正值兜底3000ms）；CraneService 创建客户端未传该参数，天车请求当前使用客户端默认3000ms。获得锁后建立 linked token 并 CancelAfter，通信期限覆盖该次连接、发送、接收；等待通信锁的时间不在此期限内，仅受调用者令牌约束。

内部期限到期、调用者没有取消：关闭连接，抛 TimeoutException 并保留内部取消异常。调用者真的取消：保持 OperationCanceledException。其他通信故障也断开；后续请求再尝试连接，不在同一次失败请求里自动重试整个动作。

天车命令将连接/通信失败转换为 CraneCommandResult，取消异常继续传播。完整状态读取失败返回 null；单个状态线圈失败可为 null。设备采集失败发布 Bad/断开的空点表。三种接口的失败表达不同，不能统称“所有失败都抛异常”或“都当无板”。

通信锁覆盖一次请求，不覆盖整套运动/握手；自动与手动共享驱动时多个动作仍可能交错。

## 3. FOCAS 通道

源码：[FocasLatheChannel](../src/AutomatedLine.Infrastructure/Communication/FocasLatheChannel.cs)、[LatheFocasDriver](../src/AutomatedLine.Infrastructure/Drivers/LatheFocasDriver.cs)。每通道专用线程与任务队列，同一个 SDK 句柄在该线程调用。读宏 cnc_rdmacro，写宏 cnc_wrmacro。

连接/SDK 通道使用固定 3s 设置，不取 App.Collection.CommunicationTimeoutMs。取消等待不保证已排队的原生调用立即中断，不能解释成 PLC 动作已撤销。

## 4. 天车完整状态读取

源码：[CraneService](../src/AutomatedLine.Infrastructure/Communication/CraneService.cs)、[CraneAddress](../src/AutomatedLine.Infrastructure/Communication/CraneAddress.cs)。D 地址与 0 基 PDU 一致。X 编号为八进制，线圈基址 63488；X11 为 63497。

后台CraneStateCollector调用完整状态读取供大屏、手动页、调度与冷启动复用；运动和动作确认仍即时读取。

结果存在CraneStateStore按CraneId索引的内存字典，消费者GetFreshStatus不通信；后台每车读完再等默认500ms，两个页面每1s应用缓存，二者不是同一频率。状态失败或从读取开始超过最大年龄时不提供有效结果；IManualOperationService.ReadStatusAsync仍保留即时读取入口，但当前页面展示已不调用。完整职责见[共享采集说明](天车状态采集设计.md)。

一次 ReadStatusAsync 顺序请求：FC03 D5000 起 30 Word、FC03 D2501 起 21 Word，再逐个 FC01 读九个 X 线圈，共 11 次请求。

| 数据 | 地址 | 解码 |
|---|---|---|
| X/Y/Z 回原点完成 | D5006 / D5007 / D5008 | 非零为已完成 |
| 伺服/PLC伺服指令/PLC报警 | D5011 / D5012 / D5013 | 原值；任一非零 HasAlarm=true |
| X 编码器 | D5014～D5015 | 有符号 DINT，低 Word 在前 |
| X 显示值 | D5018～D5019 | 有符号 DINT，低 Word 在前 |
| Y 编码器/显示值 | D5020 / D5022 | 单 Word 数值 |
| Z 编码器/显示值 | D5023 / D5025 | 单 Word 数值 |
| X 速度/加速/减速 | D2501～D2503 | 单 Word |
| Y 速度/加速/减速 | D2510～D2512 | 单 Word |
| Z 速度/加速/减速 | D2519～D2521 | 单 Word |

| 点 | 线圈地址 | 名称 |
|---|---:|---|
| X0 | 63488 | 接液盘门开到位 |
| X1 | 63489 | 接液盘门关到位 |
| X2 | 63490 | 磁铁下压限位 |
| X3/X4/X5 | 63491/63492/63493 | 三轴物理原点输入 |
| X6 | 63494 | 充磁反馈 |
| X7 | 63495 | 退磁反馈 |
| X11 | 63497 | 有板，唯一已使用有板点 |

D5029 不作为有板点。专用 ReadHasPlateAsync 只读 X11，读取失败抛异常，不返回 false 冒充无板。

取料流程在原位及每次补降成功后等500ms专用读X11，0才按App.StateMachine的PickPlateRetryCount和PickPlateStepMm有限补降，默认追加3次×5mm；X11读取失败立即停止，不继续下压。每个成功读取的检查点还经ReadStatusAsync即时读显示/编码器坐标写诊断日志，不以该DTO的HasPlate或共享缓存替代专用判据。坐标不可用记未知，调用者取消传播；这会增加检查点的实时状态请求，非页面刷新请求。

## 5. 手动前置与命令脉冲

运动、充退磁、原点、接液盘、伺服、减速停及清报警等需要手动前置的操作通过模式缓存写 D4001=2、D4500=2；显式 ConnectAsync/DisconnectAsync 和下压收尾会清缓存；客户端请求失败后的隐式重连没有单独清此前置缓存。急停直接写，不先切模式。设置速度直接写九个速度寄存器，也不套用这一前置。

| 命令 | 时序 | 完成判据 |
|---|---|---|
| 充磁 | D4510=2 → 200ms → 0 → 单读 X6 | 1 成功 Completed；0 失败 Rejected |
| 退磁 | D4511=2 → 200ms → 0 → 单读 X7 | 1 成功 Completed；0 失败 Rejected |
| X/Y/Z 回原点 | D4508/4507/4506=2 → 200ms → 0 | 命令写完；不等待原点反馈完成 |
| 开/关接液盘 | D4512/4513=2 → 200ms → 0 | 命令写完；不等待 X0/X1 |
| 清报警 | D4514=2 → 200ms → 0 | 命令写完 |
| 伺服断/通电 | D4515/4516=2 → 200ms → 0 | 命令写完 |
| 减速停止/急停 | D4517/4518=2 → 200ms → 0 | 命令写完 |

充退磁不重试、不轮询 3s、不再使用 FeedbackTimeout，退磁不另检查 X6。单次反馈失败由自动流程的 TransferContext 转成异常；手动页面直接显示结果。

一般脉冲按顺序执行；当前并非每个命令都在 finally 不可取消复位。运动触发复位有专门 finally，不能将它的保证扩展到所有命令。

## 6. 绝对和相对运动

| 类型 | 目标计算 | 到位读取基准 |
|---|---|---|
| 绝对 | 写值=用户绝对目标−当前编码器+当前显示值 | 编码器：D5014/15、D5020、D5023 |
| 相对 | 非零轴写值=当前显示值+相对增量；零增量轴不参加 | 显示值：D5018/19、D5022、D5025 |

三个目标各占 DINT：D3102/03、D3104/05、D3106/07，FC16 低 Word 在前。内部 -1 表示跳过该轴；相对三轴全 0 返回 Rejected。

Z 增大按下降处理：先 XY 脉冲 500ms 并等 XY 到位，再 Z 脉冲 500ms；Z 减小先 Z 脉冲并等 Z，再 XY；Z 不变同时触发参加轴。最终 PollAxes 每 200ms 读状态判断参与轴，默认正常容差 5mm、单轮询调用超时 60000ms。分阶段移动可有多个独立轮询期限。

参与轴触发 D4522(X)、D4521(Y)、D4520(Z)；finally 用 CancellationToken.None 尽力写 0，写失败仅记警告，不能保证断网时 PLC 确实收到复位。

无板补降复用MoveRelativeAsync(0,0,正整数步长)，当前Z正向为下降，仅Z参与，X/Y不移动。每步沿用现有脉冲、到位容差、运动期限和X2下压结果；运动失败直接充磁前异常，不额外重试。补降日志累计指令距离，与实时位置分列，不承诺实际移动量精确等于配置步长。

旧 JogAsync 使用 D4501 距离、D4502 方向、D4503/04/05 触发，当前实现只写触发，不等待到位也不自动复位。当前手动页相对移动按钮走 MoveRelativeAsync，不走这个旧入口。

## 7. 下压判定

仅 Z 下降的最终运动轮询读 X2。X2=1 时执行 D4518 急停脉冲、重写手动前置、D4514 清报警脉冲，再按 Z 差值：≤PressureToleranceMm（默认 15）为 PressureReached 成功，否则 PressureOutOfRange 失败。

当前下压检查 IsPressureLimitOnAsync 读取失败记警告并返回 false；它与状态展示线圈失败返回 null 的行为不同。D4523 常量存在，但此下压收尾实际使用 D4518，没有 D4523 自动恢复序列。

PollAxes 读取了报警寄存器，但到位结果按坐标、X2 和期限判断，不另按这些报警值中止；现场 PLC 负责运动联锁。调度选车用有效缓存检查HasAlarm；WaitCraneAsync保留实时读取和报警检查的定义，但当前没有调用，不能写成所有运动都经过这个等待函数。

## 8. 命令结果

CraneCommandResult 包含 IsSuccess、Code、Message。当前成功包括 Completed、InPosition、PressureReached；失败可能为 Timeout、PressureOutOfRange、NotConnected、Communication、Rejected。Alarm、FeedbackTimeout 等枚举仍存在，不代表所有命令都会生成这些值。

到位超时是结果码 Timeout；Modbus 请求超时是 TimeoutException，再由命令封装映射通信失败。这两个超时层级需分开排查。

## 9. 设备点位的读写范围

ModbusDeviceDriver.ReadAllSignalsAsync 只采集 Writable=false 点，按点单次读取；参数和写握手不自动读回。斜床快照例外，固定读 #1001～#1005 和 #1101～#1105 共十个宏，其中后五个是上位机输出。

设备具体地址、点名和交接顺序见[文档索引](README.md)。等待设备握手使用后台缓存；写设备参数/握手则是实际通信请求。
