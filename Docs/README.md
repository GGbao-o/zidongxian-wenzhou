## 当前实现要点

- 设备与天车分别后台采集；大屏、手动页、调度和冷启动共用天车有效快照，运动与动作确认仍即时读取。详见[天车状态采集设计](天车状态采集设计.md)。
- 路权与设备预约在状态机执行开始时真正获取，调度器只预检查。
- 取料下降到位后等 500ms，只读一次 X11。有板后，在调用充磁前设置异常分流标志。
- 充磁与退磁均为“写 2 → 200ms → 写 0 → 单次读反馈”，分别检查 X6、X7；没有三次重试或 3s 反馈轮询。
- 取料充磁调用前发生异常：保留工件，回 Waiting，释放资源、清天车任务、故障暂停并报警。调用开始后异常：弃板并清关联内存引用。
- 手动页可中止所选天车当前搬运：始终弃板、故障暂停并报警，只取消本次执行令牌。Worker 保持存活，其他已在途天车继续；现场处理后恢复线路可接新任务，详见[操作说明](页面布局/手动操作页面.md#7-中止当前任务)（2026-10-09 更新）。
- 异常协调器处理内存和线路状态，不负责把天车移回安全位或复位 PLC 握手。现场处理完成后可以重新启动线路。
- 工件、候选、路权、预约和活动报警不保存到数据库，进程重启不会恢复这些数据。
