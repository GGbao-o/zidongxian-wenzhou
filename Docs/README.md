# 项目文档索引

本文档集按 **2026-10-19 工作区源码**更新，包含天车共享采集、状态机入口暂停回滚、取料无板有限补降、ERP批量接收、大屏卡片、带托料架双头镗交互和Z补偿公式。ZDrop现为斜床/研磨单系数`Round((直径/2)/0.9537)`，双头镗及其余设备双系数`Round((直径/2)/0.9537+(直径/2)/0.866)`。本次同步打号机FC04四Word批量读取及专用尾零适配、通信异常报文日志、手动页加宽速度输入和六向相对移动按钮；打号机正常读写恢复连接复用，其他设备不启用尾零适配。类注释、界面提示与方法实现不一致时，以实际方法和XAML绑定为准。现场PLC信号定义和联锁由现场确认；这里记录上位机如何读取、使用与显示它们。

研磨机自动派发新增只读模式点`AutoMode`（FC03/PDU12063）：数值1才允许作为源或目标生成候选，调度入队前复核最新缓存；大屏悬浮显示原值及允许状态，未知不当作0。协议和执行边界见[研磨机说明](设备寄存器地址/研磨机地址.md)。

## 当前实现要点

- 设备与天车分别后台采集；大屏、手动页、调度和冷启动共用天车有效快照，运动与动作确认仍即时读取。详见[天车状态采集设计](天车状态采集设计.md)。
- 天车PLC结果按CraneId存CraneStateStore单例字典，不写DeviceBase.Signals或数据库；设备采集只筛选IDeviceDriver，两类Id分别管理。
- 大屏与手动页各自每1s应用共享缓存，再由PropertyChanged更新绑定；手动页选车后自动显示，调快采集不会改变UI节拍。
- 大屏设备按ProcessRoute工艺顺序、同类型按Id排列，设备区和参数分类卡片均固定两行。设备卡面显示工件、尺寸、预约天车和机型关键信号；内存工件与PLC加工状态分开，不再凭工件引用显示加工中。
- 天车卡面显示任务工件、最近执行步骤、单行XYZ、路权和内存持板，取料前也按任务关联显示工件；X11、充退磁和报警用1/0/未知标签呈现，无有效坐标时显示“—”。CurrentStep仅供展示，清任务时清除，不改变原业务执行；详细字段、悬浮内容和样式见[大屏文档](页面布局/大屏展示页面.md)。
- 参数页“采集 → 编辑”含四项，两项天车配置已通过动态XAML绑定接入；轮间等待默认500ms、最大年龄默认2000ms，生效时机见[参数说明](页面布局/参数设置页面.md)。
- 路权与设备预约在状态机执行开始时真正获取，调度器只预检查。
- 线路状态使用volatile字段；状态机入口发现未运行时，只回滚分配、工件回Waiting、车回Idle，保留设备引用/信号及位置/工序/排位，不写PLC、不报警。人工中止/宿主取消仍优先原处理，已通过入口的搬运继续；待领取通道不清空，这不是全线原子停发。
- 取料原位及每次补降后等500ms专用读X11；明确无板才仅Z补降，默认最多3次×5mm，共最多4次检查、15mm累计指令下降。有板后才在充磁前设置异常分流标志；通信/运动失败或取消不作为无板重试。
- 补降次数和距离在JSON及参数页“状态机 → 编辑”可配置；statemachine日志列次数、单步/累计指令量、X11和实时显示/编码器坐标，读不到位置明确记未知。完整顺序和日志样例见[应用层说明](应用层设计.md#541-取料无板的有限补降与日志)。
- 充磁与退磁均为“写2 → 固定200ms → 写0 → 配置等待（默认1000ms）→ 单次读反馈”，分别检查 X6、X7；没有三次重试或 3s 反馈轮询。
- 取料充磁调用前发生异常：保留工件，回 Waiting，释放资源、清天车任务、故障暂停并报警。调用开始后异常：弃板并清关联内存引用。
- 手动页可中止所选天车当前搬运：始终弃板、故障暂停并报警，只取消本次执行令牌。Worker 保持存活，其他已在途天车继续；现场处理后恢复线路可接新任务，详见[操作说明](页面布局/手动操作页面.md#7-中止当前任务)。
- 冷启动在程序打开和每次启动线路前核对残留板，写Warning活动报警/日志，不设禁用状态、不阻止启动；不可用天车缓存默认并发最多等3s，不把未知当无板。
- Error异常窗口固定标题“线路异常（已暂停）”，详情、来源/资源、系统动作、时间依次显示；充磁前保留、充磁后弃板、人工中止与兜底原文见[报警处理页面](页面布局/报警处理页面.md#21-异常弹窗固定格式)。Warning不弹此框。
- 正常收尾回本车安全位成功后，保持目标预约和路权清目标设备握手，再释放资源并提交工件状态；双头镗、斜床、研磨机、打号机复用各自Handler，上下料架为空操作。逐点失败记警告并继续，取消沿原异常路径处理。
- 异常协调器处理内存和线路状态，不负责把天车移回安全位或复位 PLC 握手。现场处理完成后可以重新启动线路。
- 工件、候选、路权、预约和活动报警不保存到数据库，进程重启不会恢复这些数据。
