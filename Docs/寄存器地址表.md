# 天车 / 设备 寄存器地址表（初版建议，待现场确认）

> **说明**
>
> - 逻辑点位定义在代码类中：天车 `CraneSignalCatalog`、设备 `DeviceSignalCatalog`；本表把它们映射到**建议的 Modbus 地址**与用途。
> - 地址为**初版建议**（4x 保持寄存器），最终以 PLC 工程师的点位表为准；地址变化只改驱动实现，不动业务层。
> - 数据类型：`bool` 占 1 位/1 寄存器；`int` 占 1 寄存器（16 位）；`float` 占 2 寄存器（32 位，注意字节序）。
> - 标 **【未实现】** 的为预留项，代码暂未使用。

## 三、使用方法

### 3.1 自动引擎（程序）

1. **采集**：每周期读全部 R 点位（天车 1.1、设备 2.1），整体替换快照。
2. **派发后搬运**：写 `TargetX/Y/Z` → `MoveStart` 脉冲；到位读 `InPosition`。
3. **取料**：写设备 `PickRequest` + 天车 `Grip` → 读“天车有料=1 且设备有料=0”确认。
4. **放料**：写设备 `PlaceRequest` + 天车 `Release` → 读“设备有料=1 且天车有料=0”确认。
5. **异常**：任一步超时或 `Alarm=1` → 程序自动清理（释放路权/预约/锁、清内存、弃板）并暂停线路。

### 3.2 手动操作页（人工）

1. 选择天车 → 读 1.1 显示当前坐标/状态/信号。
2. **绝对运动**：写 `MoveMode=0`、`MoveSpeed*/MoveAccel*/MoveDecel*`、`TargetX/Y/Z` → `MoveStart` 脉冲。
3. **相对运动**：上位机按当前值 + 步长换算成绝对目标，再按绝对运动下发。
4. **设置参数**：只写 `MoveSpeed*/Accel*/Decel*`，不运动。
5. **清报警 / 充磁 / 放磁 / 下压**：写对应点位（脉冲类置真再复位）。
6. 手动操作**不与自动线互斥**：自动运行时人为不应操作。

### 3.3 坐标与偏移

- 数据库 `CraneConfig` 增加 `OffsetX/OffsetY/OffsetZ`（三轴偏移量），用于坐标标定/微调。
- 约定：`实际目标 = 现场坐标 + 偏移`（具体算法待现场确认后启用）。
