# 大屏展示页面（只读）

> 一屏看全现场信号与内存数据，**不提供任何控制按钮**（架构文档 §13.6）。
> 顶部应用服务卡片 + 设备卡片 + 天车卡片，**支持横竖滚动**，卡片再多也不截断。

## 1. 顶部应用服务卡片

展示调度过程的实时产物：

- 候选任务数（`TransportTaskGenerator` 产物）
- 已派发任务数（集中调度产物）

## 2. 设备卡片

- **数量 = 数据库启用（`IsEnabled=true`）的设备**（`ConfigurationLoader` 只装载启用设备）。
- 展示：
  - 设备名称、类型、加工状态（空闲/加工中）；
  - 当前工件：**版号 / 序号 / 长度 / 直径**（来自内存 `CurrentWorkpiece`）；
  - **输入信号**：该设备采集到的点位（逻辑点名=值，如 `RequestLoad=1`、`HasMaterial=1`）——只读输入信号，见架构文档 §8.2。
- **鼠标悬浮**：显示加工状态、当前工件、全部点位信号明细。
- **边框颜色（优先级：红 > 黄 > 绿）**：

| 颜色 | 条件 |
|---|---|
| 红 | 采集失败 / 超时 / 断联（`device.IsConnected == false`） |
| 黄 | 已被任务预约（`ResourceReservationManager.IsReserved(deviceId)`） |
| 绿 | 已连接且未预约 |

## 3. 天车卡片

- **数量 = 数据库启用（`IsEnabled=true`）的天车**（数据库有几台启用就有几张卡片）。
- 展示：
  - 天车名称、**XYZ** 坐标、状态；
  - 当前任务（source → target）；
  - **持有路权区间**；
  - 当前工件：**版号 / 序号 / 长度 / 直径**（来自内存 `CurrentWorkpiece`）。
- **鼠标悬浮**：显示任务、工件、source→target、设备位置等详情。
- **天车不做后台采集**（架构文档 §8.2）：**不显示点位信号**；连接/报警/坐标在刷新时**按需读** `ICraneDriver.ReadStatusAsync`。
- **边框颜色（优先级：红 > 黄 > 绿）**：

| 颜色 | 条件 |
|---|---|
| 红 | 按需读失败 / 报警 |
| 黄 | 有任务（`Runtime.CurrentTask != null`，即执行中/已占用） |
| 绿 | 空闲且读正常 |

> 天车的绿/红依赖"刷新时按需读"（页面每 1s 刷新一次）；页面不打开时不会主动读天车。

## 4. 颜色说明

- 边框颜色**只由"连接 / 预约 / 任务"决定**。
- **PLC 点位的"报警点"只是普通点位**：只在信号里显示它的 0/1，**不参与边框颜色**。
- 颜色资源（`AppStyles.xaml`）：`StatusIdleBrush`（绿）、`StatusWaitingBrush`（黄）、`StatusFaultBrush`（红）。

## 5. 刷新

- 由界面节拍器 `RuntimeTicker`（每 1s）触发刷新。
- 设备读采集缓存（`device.Signals`）；天车按需读驱动状态。
