# 设备管理页面

源码：[DevicePageView.xaml](../../src/AutomatedLine.Ui/Views/DevicePageView.xaml)、[DeviceViewModel](../../src/AutomatedLine.Ui/ViewModels/DeviceViewModel.cs)。核对日期：2026-10-08。

## 1. 布局与列表

标题“设备配置与监控（数据来自数据库）”、添加按钮、配置表、每行编辑/删除。查询全部配置含停用，按 Id 排序；列表没有 PLC 只读点位和当前工件，不按 RuntimeTicker 定时读取现场。

## 2. 每列含义

| 列 | 用途 |
|---|---|
| 设备号 Id | 领域对象、驱动、预约、工件位置关联键 |
| 名称/类型 | 展示，以及驱动、工序与 handler 选择 |
| 协议/IP/端口 | IP 用于实际连接；Protocol/Port 保存但不决定当前工厂协议/端口 |
| 物理位置X/Y/Z | X 用于覆盖/路权；XYZ 加车偏移成为运动基础目标 |
| 最小/最大直径 | 工件匹配闭区间 |
| 最小/最大长度 | 工件匹配闭区间 |
| 启用 | 决定配置装载与工序参与 |
| 操作 | 编辑/删除 |

Remark、UpdatedAt 不在当前页面 DTO 编辑项中。类型显示中文，编辑输入按枚举解析。设备类型列表见[数据字典](../数据字典.md)。

## 3. 命令和限制

Running 时入口拒绝添加/编辑/删除；其他状态可开弹窗。确认保存/删除后重查数据库并重装两类运行注册表。删除有确认框，只删配置，不操作实物或 PLC。

数值输入不能解析则沿用原值，布尔接受 true/false/1/0；类型使用 Enum.TryParse，不能等同于完整业务合法性校验。Id 编辑后按新 Id 更新/插入，旧行不自动删除。

启用一行会让对应工序参与，但当前动平衡、验点、货叉没有真实驱动和 handler；不能据此承诺已经可自动搬运。多台同类型设备通过各自 Id/位置/能力独立匹配。

## 4. 配置生效

直接改数据库需后续装载；页面保存会触发装载，但不会重建所有 Worker/任务/锁。配置变更应等待当前任务结束、处理现场并重启，详见[配置说明](../配置与运行说明.md)。实际 PLC 信号与工件看大屏，配置表边框不承担现场状态提示。
