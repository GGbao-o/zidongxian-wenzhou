# 天车管理页面

源码：[CranePageView.xaml](../../src/AutomatedLine.Ui/Views/CranePageView.xaml)、[CraneViewModel](../../src/AutomatedLine.Ui/ViewModels/CraneViewModel.cs)。核对日期：2026-10-08。

## 1. 布局与数据来源

页面标题“天车配置与监控（数据来自数据库）”，添加按钮、配置表及每行编辑/删除按钮。数据查询配置表，包含停用行，按 No 排序；不是实时天车状态表，没有 XYZ 实时值、任务、路权或 PLC 报警列，也没有 1s 采集刷新。

## 2. 表格列与用途

| 列 | 实际用途 |
|---|---|
| 天车号 Id | 运行资源、驱动及任务关联主键，由人工填写 |
| 序号 No | 排序，数据库唯一索引；可以不同于 Id |
| 名称 | 卡片、日志和人工选择显示 |
| 协议/IP/端口 | IP 生效；Protocol/Port 兼容保存，工厂仍固定 Modbus TCP 502/站号1 |
| StartX/EndX | 覆盖源/目标物理 X，闭区间 |
| 宽度 | 路权两端各外扩半宽 |
| 安全位X/安全位Z | 正常 Finish 回位；异常协调器不会执行这些运动 |
| X/Y/Z偏移 | 加设备 XYZ 生成搬运基础坐标 |
| 各轴速度/加速度/减速度 | 每次自动任务下发九个值；与手动页输入分开 |
| 启用 | 下次装载是否进入运行注册表 |
| 操作 | 编辑和删除 |

Remark、UpdatedAt 是数据库字段，但当前配置 DTO/页面不显示为可编辑项。

## 3. 添加、编辑和删除

添加/编辑用通用字段弹窗，确认保存至数据库，然后重新装载设备与天车配置。表格直接单元格编辑未开放。删除先显示确认框，确认后删配置行并装载。

Running 时命令入口拒绝配置 CRUD；只检查线路状态，不检查其他车是否已完成在途动作。暂停后也应等当前流程结束，再按[配置变更步骤](../配置与运行说明.md)处理。

数值解析失败沿用原值，布尔支持 true/false/1/0，没有完整物理参数范围校验。编辑弹窗 Id 可改；保存按新 Id 查找并更新/插入，不自动删除旧 Id 对应行，不视为关联资源重命名。

## 4. 生效与显示

保存/删除后表格重查，运行注册表重装；没有完整 Worker 重建。新增车或改范围、安全位等需完成在途处理后重启进程，不能靠再次启动线路保证全部运行对象都换成新配置。

页面使用公共卡片与配置 DataGrid，边线不表示天车实时报警。实际连接/运动状态见大屏或手动页。
