# 参数设置页面

源码：[ParamsPageView.xaml](../../src/AutomatedLine.Ui/Views/ParamsPageView.xaml)、[ParamsViewModel](../../src/AutomatedLine.Ui/ViewModels/ParamsViewModel.cs)、[ConfigService](../../src/AutomatedLine.Infrastructure/Config/ConfigService.cs)。核对日期：2026-10-19。

## 1. 布局与操作

标题、说明及分类卡片。每卡显示分类名称、用途、项目数量和编辑入口；弹窗逐项编辑名称/值，确定后写回运行目录 appsettings.json 的 App 节点，取消不应用该次弹窗输入。

分类卡片使用`UniformGrid Rows="2"`固定为两行，单卡宽度仍为300，按`Categories`顺序从左到右、先上行后下行排列；超出视口时可横向滚动，页面保留纵向滚动。该布局不改变分类顺序、编辑弹窗或保存行为。

卡片和输入项由数据绑定动态生成：`ParamsPageView.xaml` 的 ItemsControl 绑定 `Categories`，编辑窗 [ParamsDialog.xaml](../../src/AutomatedLine.Ui/Views/ParamsDialog.xaml) 的 ItemsControl 绑定 `Items`。参数名称、取值与回写逻辑在 `ParamsViewModel.RebuildCards` 定义；新增项不需要另在 XAML 手写输入框。编辑窗默认 520×520，名称列宽220，名称/值逐行显示，内容可横竖滚动，底部“确定”“取消”。

## 2. 分类项

| 分类 | 当前编辑项 |
|---|---|
| ERP接收（3） | 监听文件路径、文件检查间隔ms、文件编码；默认D:\job1\job1.txt、500、utf-8 |
| 采集（4） | 设备采集周期、天车采集周期、天车快照最大年龄、通信超时，单位ms |
| 调度（2） | 候选生成周期、调度周期，单位 ms |
| 天车（4） | 运动超时ms、到位容差mm、下压容差mm、充退磁反馈等待时间ms |
| 状态机（4） | 握手超时ms、状态机推进周期ms、取料无板追加下降次数、取料无板每次下降mm |
| 斜床搬运（每台3项） | 按设备 Id 的顶尖距离、大孔偏移、小孔偏移；没有已装载斜床时不显示此分类 |
| 日志（3） | 目录、保留天数、单文件上限字节 |

日志SampleSeconds存在但不在编辑项里。设备/天车采集周期在服务启动读取，修改后重启；天车快照最大年龄在每次查询读取，保存并重载后后续查询采用新值。冷启动缓存等待上限复用通信超时，天车客户端通信超时仍使用原默认3000ms。

“采集 → 编辑”的实际名称及 JSON 路径如下，默认值以 AppOptions 为准：

| 显示名称 | JSON 路径 | 默认值 | 生效边界 |
|---|---|---:|---|
| 设备采集周期(ms) | App.Collection.DeviceIntervalMs | 500 | 设备采集服务启动读取 |
| 天车采集周期(ms) | App.Collection.CraneIntervalMs | 500 | 天车采集服务启动读取；不改变页面固定1s节拍 |
| 天车快照最大年龄(ms) | App.Collection.CraneSnapshotMaxAgeMs | 2000 | 文件重载后后续缓存查询使用；不是轮询周期 |
| 通信超时(ms) | App.Collection.CommunicationTimeoutMs | 3000 | 设备Modbus驱动构造、每次冷启动缓存等待；不是天车客户端超时设置 |

直接维护源码目录和程序运行目录的实际appsettings.json，已删除额外模板文件。已有运行JSON缺项时仍可采用默认值，页面确认保存整体App时写入运行目录；补字段要核对实际JSON，而不是只改一份模板。

“天车 → 编辑”包含“充退磁反馈等待时间(ms)”，JSON为`App.Crane.MagnetFeedbackDelayMs`，默认1000。充磁/退磁的写2→200ms→写0保持固定；只有写0完成后按该参数等待，再单次读X6/X7。0表示不额外等待，负数在任何PLC写入前返回失败。每次动作开始读取配置，文件重载后下一动作采用新值，无需重启；当前动作保持本次值，等待可被当前任务令牌取消。新字段由原ItemsControl自动生成输入框，不增加静态XAML控件。

“状态机 → 编辑”新增两个动态输入项：

| 显示名称 | JSON路径 | 默认值 | 语义 |
|---|---|---:|---|
| 取料无板追加下降次数 | App.StateMachine.PickPlateRetryCount | 3 | 不含原取料位检查，最多追加3次，0关闭补降 |
| 取料无板每次下降(mm) | App.StateMachine.PickPlateStepMm | 5 | 每次仅Z相对下降的指令距离，必须正整数 |

每次检查前等500ms；默认原位加3次补降，最多4次专用X11读取、15mm累计指令下降。新搬运上下文在文件重载后读取新配置；当前已开始的检查不改变配置。页面仍按Items动态生成，未增加静态XAML控件；解析错误转0的原行为不变，执行时负次数/非正距离会在充磁前报配置异常。只影响自动取料，不改变放料或手动充磁命令。

缺少斜床参数时，页面重建卡片会在其缓存选项里创建默认项（顶尖距离0、大孔122、小孔55）；确认保存时整体写入。

## 3. 保存范围与输入

页面缓存一份 AppOptions，确定后应用该类别的值，再整体保存 App；ConfigService 保留 JSON 其他根节点，包括 ConnectionStrings，按当前序列化命名格式写回。该页不编辑数据库资源配置。

没有 Running 状态保存门禁，也没有完整数值范围校验；整数/浮点解析失败转 0。单项应用或保存失败在当前 ViewModel 中写 Console 信息，没有额外失败弹窗；随后仍按本页内存选项重建卡片，因此“关闭弹窗”或卡片显示新值不能单独证明磁盘已成功保存。

## 4. 何时生效

ERP接收三项由监听循环每轮重新读取；文件保存并重载后下一轮采用新值，不需要重启。当前批次按读取时的路径/编码完成清理，暂停监听不是暂停线路。检查间隔必须正数，路径不能为空，编码支持utf-8/gbk；配置错误只影响ERP接收，不暂停线路。详见[ERP文件接收说明](../ERP文件接收说明.md)。

充退磁反馈等待时间由CraneService每次动作读取。后台周期在服务启动时读取，驱动构造时读取通信/运动超时与容差参数，日志器构造时读取日志选项；这些不能保证保存后立即替换已有实例。通信超时项用于设备Modbus及冷启动缓存等待；天车CraneService未传这个配置值，客户端仍用默认3000ms。新搬运上下文会获取配置选项，用于握手超时和斜床搬运参数。

ConfigService 通过启用 reloadOnChange 的 IConfiguration 查询配置，写盘后重载存在延迟；后续缓存查询采用新的最大年龄是指配置已重载后，不是点击确定的同一瞬间。参数页重建卡片使用自己的内存选项，不重新读配置，避免延迟重载把输入显示回旧值。

统一可靠生效方式是在完成在途及现场处理后重启程序，具体默认值见[配置说明](../配置与运行说明.md)。卡片项目数代表可编辑字段数，不代表该类别所有 AppOptions 字段。
