# 参数设置页面

源码：[ParamsPageView.xaml](../../src/AutomatedLine.Ui/Views/ParamsPageView.xaml)、[ParamsViewModel](../../src/AutomatedLine.Ui/ViewModels/ParamsViewModel.cs)、[ConfigService](../../src/AutomatedLine.Infrastructure/Config/ConfigService.cs)。核对日期：2026-10-11。

## 1. 布局与操作

标题、说明及分类卡片。每卡显示分类名称、用途、项目数量和编辑入口；弹窗逐项编辑名称/值，确定后写回运行目录 appsettings.json 的 App 节点，取消不应用该次弹窗输入。

卡片和输入项由数据绑定动态生成：`ParamsPageView.xaml` 的 ItemsControl 绑定 `Categories`，编辑窗 [ParamsDialog.xaml](../../src/AutomatedLine.Ui/Views/ParamsDialog.xaml) 的 ItemsControl 绑定 `Items`。参数名称、取值与回写逻辑在 `ParamsViewModel.RebuildCards` 定义；新增项不需要另在 XAML 手写输入框。编辑窗默认 520×520，名称列宽220，名称/值逐行显示，内容可横竖滚动，底部“确定”“取消”。

## 2. 分类项

| 分类 | 当前编辑项 |
|---|---|
| 采集（4） | 设备采集周期、天车采集周期、天车快照最大年龄、通信超时，单位ms |
| 调度（2） | 候选生成周期、调度周期，单位 ms |
| 天车（3） | 运动超时 ms、到位容差 mm、下压容差 mm |
| 状态机（2） | 握手超时 ms、状态机推进周期 ms |
| 斜床搬运（每台3项） | 按设备 Id 的顶尖距离、大孔偏移、小孔偏移；没有已装载斜床时不显示此分类 |
| 日志（3） | 目录、保留天数、单文件上限字节 |

日志SampleSeconds存在但不在编辑项里。设备/天车采集周期在服务启动读取，修改后重启；天车快照最大年龄在每次查询读取，保存并重载后后续查询采用新值。冷启动缓存等待上限复用通信超时，天车客户端通信超时仍使用原默认3000ms。

“采集 → 编辑”的实际名称及 JSON 路径如下，默认值以 AppOptions 为准：

| 显示名称 | JSON 路径 | 默认值 | 生效边界 |
|---|---|---:|---|
| 设备采集周期(ms) | App.Collection.DeviceIntervalMs | 500 | 设备采集服务启动读取 |
| 天车采集周期(ms) | App.Collection.CraneIntervalMs | 500 | 天车采集服务启动读取；不改变页面固定1s节拍 |
| 天车快照最大年龄(ms) | App.Collection.CraneSnapshotMaxAgeMs | 2000 | 文件重载后后续缓存查询使用；不是轮询周期 |
| 通信超时(ms) | App.Collection.CommunicationTimeoutMs | 3000 | 设备Modbus驱动构造、每次冷启动缓存等待；不是天车客户端超时设置 |

示例配置已包含两项天车参数；已有运行 JSON 缺项时用默认值，页面确认保存整体 App 时会写入。示例文件不等于已修改部署服务器的实际配置文件。

缺少斜床参数时，页面重建卡片会在其缓存选项里创建默认项（顶尖距离0、大孔122、小孔55）；确认保存时整体写入。

## 3. 保存范围与输入

页面缓存一份 AppOptions，确定后应用该类别的值，再整体保存 App；ConfigService 保留 JSON 其他根节点，包括 ConnectionStrings，按当前序列化命名格式写回。该页不编辑数据库资源配置。

没有 Running 状态保存门禁，也没有完整数值范围校验；整数/浮点解析失败转 0。单项应用或保存失败在当前 ViewModel 中写 Console 信息，没有额外失败弹窗；随后仍按本页内存选项重建卡片，因此“关闭弹窗”或卡片显示新值不能单独证明磁盘已成功保存。

## 4. 何时生效

后台周期在服务启动时读取，驱动构造时读取通信/运动参数，日志器构造时读取日志选项；这些不能保证保存后立即替换已有实例。通信超时项用于设备Modbus及冷启动缓存等待；天车CraneService未传这个配置值，客户端仍用默认3000ms。新搬运上下文会获取配置选项，用于握手超时和斜床搬运参数。

ConfigService 通过启用 reloadOnChange 的 IConfiguration 查询配置，写盘后重载存在延迟；后续缓存查询采用新的最大年龄是指配置已重载后，不是点击确定的同一瞬间。参数页重建卡片使用自己的内存选项，不重新读配置，避免延迟重载把输入显示回旧值。

统一可靠生效方式是在完成在途及现场处理后重启程序，具体默认值见[配置说明](../配置与运行说明.md)。卡片项目数代表可编辑字段数，不代表该类别所有 AppOptions 字段。
