# 参数设置页面

源码：[ParamsPageView.xaml](../../src/AutomatedLine.Ui/Views/ParamsPageView.xaml)、[ParamsViewModel](../../src/AutomatedLine.Ui/ViewModels/ParamsViewModel.cs)、[ConfigService](../../src/AutomatedLine.Infrastructure/Config/ConfigService.cs)。核对日期：2026-10-08。

## 1. 布局与操作

标题、说明及分类卡片。每卡显示分类名称、用途、项目数量和编辑入口；弹窗逐项编辑名称/值，确定后写回运行目录 appsettings.json 的 App 节点，取消不应用该次弹窗输入。

## 2. 分类项

| 分类 | 当前编辑项 |
|---|---|
| 采集（2） | 设备采集周期、通信超时，单位 ms |
| 调度（2） | 候选生成周期、调度周期，单位 ms |
| 天车（3） | 运动超时 ms、到位容差 mm、下压容差 mm |
| 状态机（2） | 握手超时 ms、状态机推进周期 ms |
| 斜床搬运（每台3项） | 按设备 Id 的顶尖距离、大孔偏移、小孔偏移；没有已装载斜床时不显示此分类 |
| 日志（3） | 目录、保留天数、单文件上限字节 |

日志 SampleSeconds 在 AppOptions 中存在，当前不在页面编辑项里。“采集”说明文字提到设备/天车采集，但实际只有设备采集周期，无独立天车后台周期配置。

缺少斜床参数时，页面重建卡片会在其缓存选项里创建默认项（顶尖距离0、大孔122、小孔55）；确认保存时整体写入。

## 3. 保存范围与输入

页面缓存一份 AppOptions，确定后应用该类别的值，再整体保存 App；ConfigService 保留 JSON 其他根节点，包括 ConnectionStrings，按当前序列化命名格式写回。该页不编辑数据库资源配置。

没有 Running 状态保存门禁，也没有完整数值范围校验；整数/浮点解析失败转 0。保存失败写提示/日志，不应把“关闭弹窗”直接理解为保存成功。

## 4. 何时生效

后台周期在服务启动时读取，驱动构造时读取通信/运动参数，日志器构造时读取日志选项；这些不能保证保存后立即替换已有实例。通信超时项当前用于设备Modbus；天车CraneService未传这个配置值，客户端仍用默认3000ms。新搬运上下文会获取配置选项，用于握手超时和斜床搬运参数。

统一可靠生效方式是在完成在途及现场处理后重启程序，具体默认值见[配置说明](../配置与运行说明.md)。卡片项目数代表可编辑字段数，不代表该类别所有 AppOptions 字段。
