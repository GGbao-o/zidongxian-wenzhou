# 主页面

> 线路总控 + 工件任务队列。核心：一个"启动/暂停入线"按钮、一张工件任务列表。
> 对应架构文档 §13.1。

## 1. 概览卡片

- **线路状态**：未启动 / 启动中 / 自动运行 / 请求暂停 / 已暂停 / 故障暂停（含状态色）。
- **工件任务**：内存任务总数。
- **设备 / 天车**：已装载数量。

## 2. 入线按钮（启动 / 暂停共用一个）

- **默认显示"启动线路"**；线路运行中显示**"暂停线路"**。点一下切换。
- **启动**：先冷启动核对，再 `LineControlService.Start()` → 生成器等服务开始工作。
- **暂停**：`LineControlService.Pause()` → 生成器停止（清空候选池），采集仍在后台进行。
- 这是**线路级**，与单条任务的"启动/暂停"不同。

## 3. 工件任务列表

列：

| 列 | 说明 |
|---|---|
| 板号 / 序号 | 工件自身数据（`WorkpieceInfo`） |
| 直径 / 长度 | 工件自身数据 |
| 左堵厚 / 右堵厚 | 工件自身数据 |
| 堵孔 | 70（小孔）/ 100（大孔） |
| 内孔锥度 / 圆角大小 | 工件自身数据 |
| 打印内容 | 工件自身数据（打号用） |
| **斜床工艺** | 工件自身数据（写入斜床宏 `#909` 加工模式，取值 1~10） |
| 当前工序 | 工件当前所处工序 |
| **入线顺序** | 上料架取板顺序（见 §4）；未入队显示 `-` |
| 当前位置 | `WorkpieceLocation` 文本 |
| **下一道工序** | `ProcessRoute.GetNextAvailable` 现算（跳过无启用设备节点） |
| **下一道工序位置** | 该工序目标设备（启用）的 X 位置；多个逗号分隔 |
| 状态 | 未启动 / 排队中 / 已暂停 / 已派发 / 执行中 / 已完成 / 已丢弃 |
| 操作 | 编辑 / 启动 / 暂停 / 删除（见 §5） |

## 4. 入线顺序语义（上料架待取板队列排位）

- **入线顺序 = 当前上料架队列里的排位（1、2、3…连续）**，只有"已启动、排队中、在队列"的任务占位。
- 点**启动**：入队（排到**队尾**），状态 `排队中`。
- 点**暂停**：出队，状态 `已暂停`；**后面的任务自动补位**（排位保持连续）；再次启动重新入队尾。
- 点**添加**：只出现在列表里（**未启动**），**不入队、不占位、不生成任务**，排位显示 `-`。
- **队头** = 排位 1 的任务；生成器**只给队头**生成上料候选。没有队头 = 无任务。
- 天车把队头取走（状态变"已派发"）后即出队，后面整体前移。

## 5. 行内操作

| 按钮 | 可用状态 | 作用 |
|---|---|---|
| **编辑** | **仅未启动** | 修改工件数据：长度 / 直径 / 左堵厚 / 右堵厚 / 堵孔 / 打印内容 / 内孔锥度 / 圆角大小 / 斜床工艺。**版号、序号不可改**（身份字段） |
| 启动 | 未启动 / 已暂停 | 入队尾，参与候选生成 |
| 暂停 | 排队中 | 出队，不生成候选；再次启动重新入队尾 |
| 删除 | 未启动 / 排队中 / 已暂停 / 已丢弃 / 已完成 | 从内存移除；删除前先清设备/天车对该工件的引用（已派发/执行中不可删） |

> **编辑为什么只开放"未启动"**：一旦入线，工件可能已被天车取走、或已经过某道设备按**旧**参数加工
> （长度 / 直径 / 斜床工艺都已下发过），此时改数据会出现"前一道按旧参数、后一道按新参数"的错配。
> `已暂停` 也算入过线，同样不允许。
>
> 除界面按钮置灰外，**服务端（`RuntimeTaskManager.TryUpdate`）会以同一判据再判一次** ——
> 按钮可用性来自界面上次刷新（1s 节拍），弹窗打开期间任务可能已经被启动。
> 数据以**整体替换**方式写入并**沿用 `RuntimeId`**（任务身份不变），改动前后写 `Logs/日期/operation.txt`。

## 6. 刷新

- **结构变化**（增删任务、启动/暂停入队）由 `RuntimeTaskManager.Changed` 触发**全量重建**任务列表。
- **进度变化**（状态、当前位置、当前工序、入线顺序、下一道工序）由应用层直接改领域对象、**不发事件**，
  因此由界面节拍器 `RuntimeTicker`（每 1s）**就地刷新**各行文本；
  行数或任务标识变化时退化为全量重建。**就地刷新不重建集合**，避免选中行与滚动位置每秒被清掉。
- 概览卡的"设备 / 天车"数量随同一节拍刷新，配置重载后无需外部再调 `RefreshRegistries`。
- 线路状态由 `LineControlService.StateChanged` 驱动按钮与状态文本。
