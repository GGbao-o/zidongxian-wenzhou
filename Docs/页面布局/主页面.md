# 主页面

> 线路总控 + 工件任务队列。核心：一个"启动/暂停入线"按钮、一张工件任务列表。
> 对应架构文档 §13.1。

## 1. 概览卡片

- **线路状态**：未启动 / 启动中 / 自动运行 / 请求暂停 / 已暂停 / 故障暂停（含状态色）。
- **工件任务**：内存任务总数。
- **设备 / 天车**：已装载数量。

## 2. 入线按钮（启动 / 暂停共用一个）

- **默认显示"启动线路"**；线路运行中显示**"暂停线路"**。点一下切换。
- **启动**：先冷启动核对，再 `LineControlService.Start()` → 生成器等服务开始工作。
- **暂停**：`LineControlService.Pause()` → 生成器停止（清空候选池），采集仍在后台进行。
- 这是**线路级**，与单条任务的"启动/暂停"不同。

## 3. 工件任务列表

列：

| 列 | 说明 |
|---|---|
| 板号 / 序号 | 工件自身数据（`WorkpieceInfo`） |
| 直径 / 长度 | 工件自身数据 |
| 左堵厚 / 右堵厚 | 工件自身数据 |
| 堵孔 | 70（小孔）/ 100（大孔） |
| 内孔锥度 / 圆角大小 | 工件自身数据 |
| 是否动平衡 | 需要 / 不需要 |
| 打印内容 | 工件自身数据（打号用） |
| 当前工序 | 工件当前所处工序 |
| **入线顺序** | 上料架取板顺序（见 §4）；未入队显示 `-` |
| 当前位置 | `WorkpieceLocation` 文本 |
| **下一道工序** | `ProcessRoute.GetNextAvailable` 现算（跳过无启用设备节点） |
| **下一道工序位置** | 该工序目标设备（启用）的 X 位置；多个逗号分隔 |
| 状态 | 未启动 / 排队中 / 已暂停 / 已派发 / 执行中 / 已完成 / 已丢弃 |
| 操作 | 启动 / 暂停 / 删除（见 §5） |

## 4. 入线顺序语义

- 点**启动**：分配一个**递增的顺序号**（入队尾），状态 `排队中`。
- 点**暂停**：清空顺序号（出队），状态 `已暂停`；**再次启动会重新入队尾**。
- **队头** = 队列中"排队中"且顺序号最小者；生成器**只给队头**生成上料候选。
- 天车把队头工件取走后（状态变"已派发"），它即**出队**，下一个顺序号成为队头。

## 5. 行内操作

| 按钮 | 可用状态 | 作用 |
|---|---|---|
| 启动 | 未启动 / 已暂停 | 入队尾，参与候选生成 |
| 暂停 | 排队中 | 出队，不生成候选；再次启动重新入队尾 |
| 删除 | 未启动 / 排队中 / 已暂停 | 从内存移除（已派发/执行中不可删） |

## 6. 刷新

- 任务列表在 `RuntimeTaskManager.Changed` 时全量重建。
- 线路状态由 `LineControlService.StateChanged` 驱动按钮与状态文本。
