# 工序展示页面

源码：[ProcessPageView.xaml](../../src/AutomatedLine.Ui/Views/ProcessPageView.xaml)、[ProcessViewModel](../../src/AutomatedLine.Ui/ViewModels/ProcessViewModel.cs)、[ProcessRoute](../../src/AutomatedLine.Domain/Routing/ProcessRoute.cs)。核对日期：2026-10-08。

## 1. 布局和列

只读工序表固定八行：上料、双头镗、斜床、研磨、动平衡、打号、验点、下料。

| 列 | 含义 |
|---|---|
| 顺序 | 固定路线的先后顺序，不可拖动修改 |
| 工序 | ProcessType 的中文文本 |
| 设备类型 | 对应 DeviceType |
| 状态 | 存在启用的该类型设备显示“参与工艺”，否则“无设备 · 跳过” |
| 设备数量 | 运行注册表中的对应启用设备数 |

## 2. 判定与刷新

每 1s 从设备注册表重算。参与只看启用类型存在；不检查联网、报警、工件、预约、驱动或 handler。离线设备仍可使工序显示参与。主页面下一工序与生成器使用相同固定路线规则。

Forking 虽有枚举但不在此八行路线内。动平衡/验点启用会显示参与，但当前驱动与搬运策略未实现；此页不是“现场可执行能力”检测，也没有编辑路线按钮。

表格只展示，没有工件加工进度百分比或 PLC 控制，使用公共页面样式。
