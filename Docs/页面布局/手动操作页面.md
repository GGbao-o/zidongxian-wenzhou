# 手动操作页面

源码：[ManualOperationPageView.xaml](../../src/AutomatedLine.Ui/Views/ManualOperationPageView.xaml)、[ManualOperationViewModel](../../src/AutomatedLine.Ui/ViewModels/ManualOperationViewModel.cs)、[ManualOperationService](../../src/AutomatedLine.Infrastructure/Manual/ManualOperationService.cs)、[CraneWorker](../../src/AutomatedLine.Application/Workers/CraneWorker.cs)。核对日期：2026-10-17。真实寄存器和运动算法完整见[通信说明](../通信与点位说明.md)。

## 1. 页面结构和刷新

顶部第一行选择天车、刷新按钮、连接徽标；第二行显示当前搬运、“中止当前任务”按钮和现场停止提示，宽度不足时换行。滚动内容包括只读状态、设置速度、绝对移动、相对移动、动作、回原点、设备握手复位；底部 Message 显示操作结果。

天车下拉来自启用数据库配置，按No排序，构造时装载，不持续刷新下拉。选择天车立即应用有效共享快照，RuntimeTicker每秒更新左侧PLC状态和Worker当前任务；刷新按钮只重新应用缓存，不直接请求PLC。成功手动操作后应用当前缓存，后续采集继续更新；自动状态刷新不覆盖Message中的操作结果。

选中天车后无需持续点刷新，左侧会自动变化。但后台是“读完再等 CraneIntervalMs（默认500ms）”，页面是固定1s取值；采集结果写到共享字典，不会直接推送到本页绑定属性。`RefreshStatus` 取出有效状态后给 XDisplay、报警、信号等属性赋值，由 PropertyChanged 更新 XAML。调快采集不改变页面1s节拍，大屏和手动页仍是两个独立 ViewModel，共用同一缓存而非互相绑定。

| 徽标 | 条件 |
|---|---|
| 灰色 | 尚未选择天车 |
| 绿色 #16A34A | 读取成功且无三个天车报警 |
| 橙色 #D97706 | 读取成功但 HasAlarm=true |
| 红色 #DC2626 | 状态不可用：未采集、失败、过期、停用或驱动身份不符 |

切车或缓存不可用时清空旧坐标、编码器、速度、报警和回原点状态，绑定空值显示“—”；X区信号也显示“—”。不保留另一台车或过期数据。大屏状态不可用时的坐标同样显示“—”。

### 1.1 按钮配色和交互状态

本页23个按钮使用`UserControl.Resources`内的具名样式，只区分操作用途，不表示PLC当前状态；状态仍以左侧反馈为准。右侧卡片按设置速度、相对移动、绝对移动、动作、握手位复位排列；左侧状态卡宽280px。配色不改变命令绑定、方向参数和原有可执行条件，不影响其他页面按钮。

| 减速停止、清除报警、清握手位 | 深橙`#B45309` / 白色 | `ManualAttentionButton` |
| 急停 | 实心红`#DC2626` / 白色 | `ManualEmergencyButton` |

急停与中止继续使用不同文字和红色深浅：急停发送PLC急停指令；中止取消所选天车当前搬运并弃板、暂停线路，不因外观调整改变两者行为。

## 2. 只读状态区每组

| 分组 | 行/字段 | 来源 |
|---|---|---|
| 显示值坐标 | X、Y、Z | D5018/19、D5022、D5025 |
| 绝对编码器坐标 | X、Y、Z | D5014/15、D5020、D5023 |
| 三轴速度/加速度/减速度 | 各轴三行，共九行 | D2501～03、D2510～12、D2519～21 |
| 回原点 | X/Y/Z 已回原点 | D5006/07/08，非零完成 |
| 报警 | 伺服报警、PLC伺服指令报警、PLC报警原值 | D5011/12/13 |
| X区信号 | X0开盘、X1关盘、X2下压、X3/4/5物理原点、X6充磁、X7退磁、X11有板 | FC01 逐点读取 |

坐标不缩放，按解码后的整数显示：X 显示值与编码器为有符号32位 DINT；Y/Z 显示值与编码器均为单 Word 有符号16位 INT，范围 -32768～32767，负数直接显示，不转成大正数。底层统一解码，因此大屏、后台快照及运动判断使用相同数值。

X 区布尔展示为是/否，读取失败为 —；D5029 不是有板点。后台完整采集包含两次寄存器批量读和九次线圈读，包含速度寄存器；页面每次刷新只查询该结果，不重复通信。

顶部任务行显示自动搬运源/目标设备 ID 和搬运短号；本页没有工件明细或路权控制字段。状态卡采用公共卡片边框，连接状态由徽标体现，不能套用大屏有任务橙框的规则。

## 3. 速度和运动输入

设置速度卡片宽420px，九个输入框各宽110px，每轴一行显示速度/加速度/减速度。设置速度仍读取本页九个输入并写对应寄存器；不是改数据库，也不是给主页面新建工件设速度。自动任务仍会下发该车数据库速度配置。

页面新建时的输入初值如下，不根据左侧PLC状态自动覆盖，点击“设置速度”才写入所选天车：

| 轴 | 速度 | 加速度 | 减速度 |
|---|---:|---:|---:|
| X | 100 | 50 | 30 |
| Y | 60 | 30 | 20 |
| Z | 40 | 20 | 20 |

绝对移动输入 AbsX/Y/Z，以编码器目标为准：写值为目标−当前编码器+当前显示值，轮询编码器。相对移动卡片宽240px，上方只有一个RelativeStep步长输入框（mm，正整数，初始0）；下方X+/X-、Y+/Y-、Z+/Z-按两列三行排列。点击时只给所选轴传入正/负步长，其他两轴为0，继续调用原ManualOperationService.MoveRelativeAsync，以显示值为基准计算目标、轮询显示值到位。

步长保留为文本，点击时校验为大于0的整数；空值、非法字符、0或负数只在Message提示，不发送移动命令，避免非法输入后误用上一有效值。六个按钮共用同一个异步命令，执行期间统一禁用；每次点击执行一次相对移动。速度服务、运动算法、PLC地址、时序及日志沿用原实现。

绝对移动在每次点击时先弹出“绝对移动确认”，显示本次天车和目标编码器坐标，并要求输入密码。密码来自运行目录JSON的`App.ManualOperation.AbsoluteMovePassword`，初始配置为`123123`，参数管理页面不展示此项。输入使用PasswordBox掩码，不记录密码；输错留在弹窗提示并清空输入，取消或关闭均不调用运动服务；正确确认后只执行本次移动，不记住验证结果。未选车不弹窗，密码未配置或空白时禁止执行。每次点击重新获取配置，文件重载完成后下一次确认采用新密码；弹窗期间固定本次车与坐标，确保确认内容和下发一致。此入口不影响相对移动、其他手动按钮或自动状态机。

移动使用 D3102～07 目标和 D4522/21/20 脉冲；Z下降先XY再Z，Z上升先Z再XY。默认到位容差5mm、下压容差15mm、每次运动轮询期限60s。运动脉冲500ms，充磁/退磁脉冲1000ms，其他常规动作脉冲200ms。

六个轴向按钮是单次相对移动入口，走MoveRelativeAsync，不能按旧JogAsync的D4501～05写法解释当前按钮。

## 4. 动作按钮

| 按钮 | 写入与反馈 | “成功”的含义 |
|---|---|---|
| 清除报警 | D4514=2 →200ms→0 | 完成写入，不是清活动报警列表 |
| 急停 | D4518=2 →200ms→0，无手动前置 | 完成写入，不自动取消内存任务 |
| 减速停止 | D4517 脉冲 | 完成写入 |
| 伺服通电/断电 | D4516/D4515 脉冲 | 完成写入 |
| 充磁 | D4510脉冲后单读X6 | X6=1才成功；0为Rejected |
| 放磁 | D4511脉冲后单读X7 | X7=1才成功，不额外读X6 |
| 接液盘打开/关闭 | D4512/D4513 脉冲 | 写入结束，不等待X0/X1到位 |
| X/Y/Z回原点 | D4508/4507/4506 脉冲 | 写入结束，不等待原点完成反馈 |

需要模式前置的操作会通过缓存确保 D4001=2、D4500=2，急停和九项速度写入不走此前置。X2 下压收尾实际用 D4518、重写模式、D4514；没有本页 D4523 恢复按钮。

上述 PLC 命令返回结果映射为 Message；命令失败不会直接调用自动 TaskAbortCoordinator，也不会自动把工件弃板或暂停线路。“中止当前任务”是独立的自动搬运控制入口，见第 7 节。

自动Pick中的“X11无板有限补降”是TransferContext原语，参数页配置；本页手动充磁按钮仍只发充磁脉冲并读X6，不自动检查X11或下降。自动补降中的人工中止仍取消当前任务、按原规则弃板，不因尚未充磁而保留。

## 5. 设备握手位复位

设备选择仅含启用双头镗、斜床、研磨机，按 Id 排序。清握手位共用 handler 的 ClearHandshakeAsync，逐点写0；只清输出握手，不清长度/直径等加工参数。

| 类型 | 复位点 |
|---|---|
| 双头镗 | DataSentDone 12205、LoadDone 12213、UnloadDone 12221 |
| 斜床 | DataSentDone #1101、CraneLoadInPlace #1102、CraneLoadDone #1103、CraneUnloadInPlace #1104、CraneUnloadDone #1105 |
| 研磨机 | DataTransDone 14623、LoadInPlace 14625、LoadDone 14627、UnloadInPlace 14629、UnloadDone 14631 |

双头镗已接入[新地址表](../设备寄存器地址/双头镗地址.md)：12213在退磁及回升后发上料完成，12221在充磁及回升后发下料完成；手动清理自动复用三点Handler，只复位12205/12213/12221。

单点失败记警告并继续，返回成功写入数。数量>0 手动服务即报告成功，不能据此证明全部位已清；数量0报告失败。打号机的handler现在会复位LoadDone/UnloadDone，自动中转已接入，但本页下拉筛选当前仍不列打号机；料架没有使用中的握手输出，也不在此下拉。

自动线中转到目标上方后按先源后目标清握手，正常流程之外的 Abort 不执行这一步；异常残留可由此页人工清。

## 6. 与自动线路的关系

手动页 → ManualOperationService → DriverRegistry 的 ICraneDriver；自动 Worker → 状态机/TransferContext → 同一个驱动实例。同一个连接的单次请求串行，但没有整个操作互斥，也没有“自动运行时禁用全部手动按钮”的线路门禁。

PLC 命令区只下发/展示；新增的任务中止按钮通过 Worker 和状态机处理当前自动搬运，不能解释为直接修改 PLC 信号。主页面的工件“暂停”只作用于 Waiting 工件，不能中止执行中的搬运；要弃掉所选车当前正在执行的任务，使用本页“中止当前任务”。

## 7. 中止当前任务

| 显示/按钮状态 | 含义 |
|---|---|
| 当前任务：无，按钮禁用 | 未选车、Worker 未领取、车空闲或执行已结束；不会中止通道中尚未领取的 Assigned 任务 |
| 当前任务：设备1 → 设备2（8位短号），按钮可用 | 所选车有当前搬运；短号来自 TransportTask.TaskId，不是工件 RuntimeId |
| 任务文字追加“中止中…”，按钮禁用 | 已接受该搬运的人工中止，等待流程取消及统一清理；清理完成后显示无任务 |

点击时携带本页实际显示的完整搬运 ID。Worker 校验车 ID 和搬运 ID；如果显示的任务已经结束/换单或重复中止，拒绝请求并提示刷新后的状态，不能误中止下一单。线路已经暂停时仍可中止该车已经执行的搬运。

接受后立即故障暂停线路，并取消本次搬运独立令牌。状态机记录车名、路线、阶段及“人工中止当前任务”，直接调用 TaskAbortCoordinator.Abort：无论是否已取料充磁，一律标记工件 Discarded、位置 Discarded，保留列表记录；清与该工件身份一致的源/目标引用，释放本次路权和设备预约，清车当前任务/工件/区间并置 Idle，产生故障报警。

只取消所选车的当前流程。其他天车已开始的搬运继续；候选生成、派发及新任务领取等待线路重新启动。被中止的 Worker 循环保持存活，后续搬运创建新的取消令牌，现场处理完成并重新启动线路后可继续接受其他任务。

此按钮不下发 D4518 急停、不自动回安全位、不增加 PLC 握手复位，现场负责停止天车和取走工件；需要补清设备输出时使用既有“清握手位”。取消是协作式的，当前外部调用退出后状态机进入清理。普通故障仍按充磁前保板、充磁后弃板处理，宿主停止仍清理后退出循环。

接受中止后，页面先显示“已请求中止当前任务，线路已暂停；清理后工件标记为已丢弃”。取消被流程观察并完成异常处理时，再弹“线路异常（已暂停）”；正文包含车名、工件/路线、阶段、人工中止说明、弃板处理与时间，具体原文见[报警页弹窗说明](报警处理页面.md#21-异常弹窗固定格式)。这与普通 PLC 命令失败只显示底部 Message 的行为不同。
