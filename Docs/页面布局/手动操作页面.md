# 手动操作页面设计（仅天车）

> 本项目**只有天车**（无机械手）。
> 天车**数量从数据库读取**；**IP 从数据库读取**；**端口一律 502、协议（汇川 PLC / Modbus TCP）写死**。
> 地址依据《寄存器地址表.md》与现场 PLC 协议。

---

## 1. 页面结构

1. **天车选择**：下拉框，选项来自数据库 `CraneConfig`（名称/编号），选中即针对该天车读写。
2. **刷新按钮**：手动刷新选中天车的状态（当前手动刷新；后期可改为一直轮询、页面常显）。
3. **连接状态徽标**：绿=已连接、黄=天车报警（D5011/12/13 任一非 0）、红=❌连接失败。
4. **实时状态区**（只读，刷新后显示）。
5. **操作按钮区**（下发）。

---

## 2. 读取显示（地址）

### 2.1 位置

| 显示项 | 寄存器 | 类型 | 说明 |
|---|---|---|---|
| X 显示值坐标 | D5018~D5019 | DINT，低字在前 | 当前 X |
| Y 显示值坐标 | D5022 | INT（0~65535） | 当前 Y |
| Z 显示值坐标 | D5025 | INT（0~65535） | 当前 Z |
| X 绝对值编码器坐标 | D5014~D5015 | DINT，低字在前 | X 编码器 |
| Y 绝对值编码器坐标 | D5020 | INT | Y 编码器 |
| Z 绝对值编码器坐标 | D5023 | INT | Z 编码器 |
| x轴绝对值三个速度 | D2501-D2503 | INT |  |
| y轴绝对值三个速度 | D2510-D2512 |  |  |
| z轴绝对值速度加速度减速度 | D2519-D2521 |  |  |

> 位置来自一次批量读 `D5000~D5029`（FC03，30 个字）。
>
> **用途区分**：`显示值`用于相对运动的基准与运动到位轮询；`绝对编码器值`用于绝对运动的基准（见 §3.1）。
>
> 手动页状态区会显示上述**三轴速度/加速度/减速度**（读回 D2501~D2503 / D2510~D2512 / D2519~D2521）。
>
> **运动到位超时**：每车可配，见数据库 `CraneConfig.MoveTimeoutMs`（默认 60000ms），天车管理页可编辑。

## 3. 操作按钮（寄存器时序）

**前置**：除“急停”外，所有命令前先 `D4001=2`（切手动）→ `D4500=2`（手动使能）；重连或下压急停后需重写。

| 按钮 | 寄存器时序 | 说明 |
|---|---|---|
| **设置速度** | 读取**本页输入**的三轴速度/加减速，写入 `D2501~D2503`/`D2510~D2512`/`D2519~D2521`（绝对速度，运动前应用） | 本页输入，不再读主页面 |
| **清除报警** | `D4514=2` →200ms → `D4514=0` | 脉冲 |
| **绝对移动** | 1. 读当前**绝对编码器值**坐标   `D5014~D5015`(X)/`D5020`(Y)/`D5023`(Z) 2. 写目标 `D3102~D3107` = **用户输入绝对值 − 当前绝对编码器值+当前显示值坐标**（FC16，DINT 小端）3. 按 Z 方向脉冲触发：**Z 下降**先 XY 后 Z、**Z 上升**先 Z 后 XY、**Z 不变**三轴并行；`D4522`(X)/`D4521`(Y)/`D4520`(Z) 写 2 → 500ms → 0 4. 轮询 `绝对值地址 D5014~D5015 D5020 D5023`（绝对值值）到位 ±5mm  return | finally 必须复位参与轴触发位=0 |
| **相对移动** | 1. 读当前**显示值**坐标 `D5018~D5019`(X)/`D5022`(Y)/`D5025`(Z) 2. 目标 = **当前显示值 ± 相对值**（未点动的轴保持当前显示值）3. 写目标 `D3102~D3107` = 该目标值（FC16，DINT 小端）4. 触发 写对应地址写2-写0 与轮询读取显示值 看看是否差值再范围内 在范围内就return | 相对值为页面输入 |
| **急停** | `D4518=2` → 200ms写 0 | **不切手动**，紧急直写 |
| **减速停止** | `D4517=2` →200ms写 0 | 脉冲 |
| **X 回原点** | `D4508=2` → 200ms → `D4508=0` | |
| **Y 回原点** | `D4507=2` → 200ms → `D4507=0` | |
| **Z 回原点** | `D4506=2` → 200ms → `D4506=0` | |
| **充磁** | `D4510=2` → 轮询 `X6=1` → `D4510=0` | 最多 3 次、单次 3s；成功判据 X6=1 |
| **放磁** | `D4511=2` → 轮询 `X7=1 ` → `D4511=0` | 最多 3 次 |
| **接液盘打开** | `D4512=2`-200ms → 0 | 脉冲 |
| **接液盘关闭** | `D4513=2` -200ms→ 0 | 脉冲 |
| **伺服通电** | `D4516=2` -200ms→ 0 | 脉冲 |
| **伺服断电** | `D4515=2`-200ms → 0 | 脉冲 |

> 上下压急停恢复（如需）：`D4523=0` → `D4001=2`+`D4500=2` → `D4514=2→0` → `D4516=2→0` → 复位 `D4520~D4522=0`。

### 3.1 相对运动 vs 绝对运动（重要，基准不同）

| | 基准 | 写入 `D3102~D3107` 的值 |
|---|---|---|
| **相对运动** | **显示值** `D5018~19`(X)/`D5022`(Y)/`D5025`(Z) | 目标 = **当前显示值 ± 相对值**（该目标值本身） |
| **绝对运动** | **绝对编码器值** `D5014~15`(X)/`D5020`(Y)/`D5023`(Z) | **用户输入绝对值 − 当前绝对编码器值+当前对应的显示值**（差值） |

- **相对运动**例：当前显示 `(200, 100, 200)`，相对值 `10` → `X+` 目标 `(210,100,200)`、`X-` 目标 `(190,100,200)`；未点动的轴保持当前显示值。
- **绝对运动**例：当前绝对编码器 `(500, 100, 50)`，用户输入 `(1000, 200, 300)` → 写入 `D3102~D3107` 的三个值 = `(1000-500+当前显示值x, 200-100+当前显示值y, 300-50+当前显示值z) 。
- 两者**触发方式相同、到位轮询不同**：相对运动轮询**显示值** `D5018/22/25`，绝对运动轮询**绝对编码器值** `D5014~15/20/23`；差值 ≤ 容差（默认 5mm，**可配置**）即视为到位。

> 关键点：**相对运动用显示值，绝对运动用绝对编码器值**；文档旧版写的是显示值，现按现场更正。

---

## 4. 刷新读取

1. **批量读** `D5000~D5029`（FC03，30 字），解析：显示值、编码器、回原点、报警。
2. **逐个读 X 线圈**（FC01）：`X0/X1/X2/X3/X4/X5/X6/X7/X11`。

---

## 5. 注意事项

1. **脉冲型**（D4510~D4518、D4520~D4522）写 2 触发后**必须写 0 复位**；`D4523` 触发写 2→0、恢复写 0。
2. **手动前置**：除急停 `D4518` 外，命令前 `D4001=2` + `D4500=2`；下压急停/重连后缓存失效需重写。
3. **X 区为八进制**：`X11` 线圈地址 = **63497**（不是 63499）。
4. **X 区读取失败必须抛异常**，不能按 0（无板/未下压）处理。
5. **DINT 小端低字在前**：读 `D5014~D5019`、写 `D3102~D3107`。
6. 绝对移动的 `finally` 复位触发位要用**不可取消令牌**，避免超时/取消后卡在 2。

> 页面只做展示与下发，不直接操作内存任务；手动操作**不与自动线互斥**（自动运行时人为不应操作）。
