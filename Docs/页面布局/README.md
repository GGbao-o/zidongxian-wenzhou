## 主窗口与公共样式

[MainWindow.xaml](../../src/AutomatedLine.Ui/MainWindow.xaml) 默认最大化，声明尺寸 1400×860、居中、Mica 背景；顶端自绘标题栏、横向导航、下方页面内容。导航支持横向滚动。

[ShellViewModel](../../src/AutomatedLine.Ui/ViewModels/ShellViewModel.cs) 持有全部页面 ViewModel，切换导航改变 CurrentPage；它们不是每次切页重新构造。已经订阅节拍器的页面可以在后台继续刷新。

大屏与手动页使用同一个Application天车缓存，但各有自己的ViewModel和绑定；RuntimeTicker固定每1s应用缓存，再由PropertyChanged更新WPF，后台采集周期不等于页面刷新周期。Error弹窗使用系统MessageBox，不套用下述大屏状态边框；详细格式见[报警说明](报警处理页面.md#21-异常弹窗固定格式)。

[AppStyles.xaml](../../src/AutomatedLine.Ui/Resources/Styles/AppStyles.xaml) 公共色：背景 #F1F5F9、白色卡片、文字 #0F172A、辅助文字 #64748B、边线 #E2E8F0、蓝 #2563EB、绿 #16A34A、橙 #D97706、红 #DC2626。公共 CardBorder 为 1 单位边框、圆角 10、内边距 20；大屏设备/车卡局部覆盖为2单位状态边框、16内边距，名称字号16。大屏信号使用浅绿/浅灰标签区分1、0与未知，天车报警成立为浅红底红字；执行状态为浅蓝底标签，其他页面不受这些局部样式影响。

上述尺寸是 WPF 逻辑单位；页面表格与弹窗沿用实际控件样式，不能把大屏红/橙/绿的判据直接套到所有页面。
