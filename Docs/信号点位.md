# 信号点位表

> 本文档记录设备/天车 PLC 信号点位的**逻辑点名、含义、数据类型、读写方向，以及最终 PLC 地址**。
> 说明：逻辑点名与类型定义在**代码类**中（对应《架构设计文档》§6.2、§17 不变式 8），
> PLC 地址属现场工程常量，待真实协议与点位表确定后填入本表，再由驱动实现做"点名 → 地址"映射。
> 现场接入前，采集由模拟驱动提供；点位到位后必须删除模拟驱动与样例数据，全部改用真实点位。

## 1. 设备通用点位（逻辑点名）

| 逻辑点名 | 数据类型 | 读写 | 含义 | PLC 地址 |
|---|---|---|---|---|
| HasMaterial | Bool | R | 设备有料 | 待定 |
| Alarm | Bool | R | 设备报警 | 待定 |
| RequestLoad | Bool | R | 请求上料 | 待定 |
| RequestUnload | Bool | R | 请求下料 | 待定 |
| AllowPick | Bool | R | 允许取料 | 待定 |
| AllowPlace | Bool | R | 允许放料 | 待定 |
| ProcessDone | Bool | R | 加工完成 | 待定 |
| Clamp | Bool | R/W | 夹紧 | 待定 |
| Release | Bool | W | 松开 | 待定 |

> 不同设备类型可能有专属点位，后续按设备类扩展本节。

| Alarm | Bool | R | 天车报警 | 待定 |

| CompanionSignal | Int | R | 伴信号 | 待定 |
| TargetX | Double | W | 目标 X | 待定 |
| TargetY | Double | W | 目标 Y | 待定 |
| TargetZ | Double | W | 目标 Z | 待定 |
| ActionWord | Int | W | 动作字 | 待定 |

| Grip | Bool | W | 抓取/松开 | 待定 |
