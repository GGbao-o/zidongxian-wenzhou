# 异常握手清理与手动模式实施计划

**目标：** 异常时尽力清理本次任务仍占用且已经交互的设备握手；手动页独立设置并展示D4001、D4500。

**方案：** 在CraneStateMachine现有异常分流前等待PLC清理，沿用TaskAbortCoordinator内存处置。TransferContext记录源/目标是否开始交互；预约任务ID与当前工件ID共同防止误清。独立取消期限复用Collection.CommunicationTimeoutMs，失败只记日志。手动按钮通过新SetManualModeAsync直接写两个2，不调用带缓存的EnterManualAsync；ReadStatusAsync新增两项可空Word读回，不改变ReadRawStatusAsync和运动方法。

**技术：** .NET 8、C#、WPF/MVVM、现有ModbusTCP驱动与xUnit本机通信桩。
