

modbustcp  **端口 502、站号 1**（IP 用数据库）。

- 读状态：**FC04**（输入寄存器），起始 PDU 0（1 基写法 0001），共 4 个 Word。
- 写：**FC06**（保持寄存器）；打印内容 **FC16**（多寄存器字节流）。
- 地址文档为 1 基编号（含 A 的为十六进制）；**0 基 PDU 地址 = 编号 − 1**（000A=10 → 9）。
- 所有状态与工艺参数均为 1 Word；只有打印内容是字节流多寄存器。



**自动线通讯协议**

| 寄存器名称         | 寄存器地址 | 说明                     |
| :----------------- | :--------- | :----------------------- |
| **输入寄存器控制** |            |                          |
| 设备空闲寄存器     | 0001       | 0. 设备空闲；1. 设备忙碌 |
| 设备运行寄存器     | 0002       | 0. 设备停止；1. 设备运行 |
| 加工完成寄存器     | 0003       | 0. 加工未完；1. 加工完成 |
| 设备打印文字寄存器 | 0004       | 0. 无新内容；1. 有新内容 |
| **保持寄存器**     |            |                          |
| 上料完成寄存器     | 0005       | 0. 上料未完；1. 上料完成 |
| 下料完成寄存器     | 0006       | 0. 下料未完；1. 下料完成 |
| 版辊外径           | 0007       | 单位 mm                  |
| 版辊内径           | 0008       | 单位 mm                  |
| **保持寄存器**     |            |                          |
| 打印文字寄存器     | 000A~00C8  | 待打印的内容，UTF8 编码  |

---

> **0001 的值语义（易错点）**：`0 = 设备空闲`、`1 = 设备忙碌` —— **0 才是空闲**。
> 上位机代码里该点位命名为 **`Busy`**（不叫 `Idle`），"可放料"的判据是 `Busy == false`；
> 不要按字面理解成"空闲寄存器 = 1 表示空闲"。
>
> 取料侧读的是 **0003 加工完成**（`ProcessDone == 1`），与本寄存器无关。
