# 打号机点位与交互

核对日期：2026-10-14。源码：[MarkerMachineAddress](../../src/AutomatedLine.Infrastructure/Communication/MarkerMachineAddress.cs)、[DeviceModbusMaps.Marker](../../src/AutomatedLine.Infrastructure/Drivers/DeviceModbusMaps.cs)、[ModbusDeviceDriver](../../src/AutomatedLine.Infrastructure/Drivers/ModbusDeviceDriver.cs)、[MarkerHandler](../../src/AutomatedLine.Application/Transfer/Handlers/MarkerHandler.cs)。

## 1. 通信和地址

Modbus TCP，固定502/站号1，IP来自数据库。原协议编号为1基；含字母的000A/00C8按十六进制，PDU=编号−1。

输入FC04，单点单Word逐次读取四点；地址类虽有InputStart/InputCount，当前通用驱动不使用它们合为一次FC04。输出FC06，打印文字FC16。

## 2. 后台读输入

| 协议编号 | PDU | 点名 | 值语义 |
|---|---:|---|---|
| 0001 | 0 | Busy | 0空闲、1忙碌；放料等false |
| 0002 | 1 | Running | 0停止、1运行 |
| 0003 | 2 | ProcessDone | 0未完成、1完成；取料等true |
| 0004 | 3 | NewPrintContent | 0无新内容、1有新内容 |

驱动布尔转换按非零true。Busy不叫Idle，不能误解为“1是空闲”。大屏按英文键排序为Busy、NewPrintContent、ProcessDone、Running。

## 3. 输出和工艺参数

| 协议编号 | PDU | 点名 | 写入内容 |
|---|---:|---|---|
| 0005 | 4 | LoadDone | 完整放料结束写1；中转源/目标握手复位写0 |
| 0006 | 5 | UnloadDone | 完整取料结束写1；中转源/目标握手复位写0 |
| 0007 | 6 | RollerOuterDiameter | 工件Diameter，倍率1，Round转Word |
| 0008 | 7 | RollerInnerDiameter | 工件PlugHole，70/100 |
| 000A～00C8 | 9～199 | PrintContent | 起点9，UTF-8字节转Word，FC16 |

打印编码：第1字节放Word低8位，第2字节放高8位；奇数长度最后高8位补0。例如ASCII“AB”组装为0x4241，再由Modbus客户端按Word线上格式发送。没有在当前写入方法按00C8终点自动截断，也不自动清掉上一段更长文本的尾部；终止/长度处理由现场协议配合。

## 4. 自动取放

**取料**：等ProcessDone → 源XY/SafeZ → Z下降 → 500ms后专用读X11、无板按配置仅Z有限补降 → 确认有板后标志置true/充磁 → Z升 → UnloadDone=1。

默认追加3次×5mm，每次成功后等500ms重查，共最多4次专用读取、15mm累计指令下降；耗尽、读取/运动失败仍在充磁前，保留源工件。参数与实读位置日志见[应用层说明](../应用层设计.md#541-取料无板的有限补降与日志)。放料不执行补降。

**放料**：等Busy=false → 先写PrintContent，再外径、内径 → Z下降 → 退磁 → Z升 → LoadDone=1。没有请求数据/请求上料或数据下发完成握手；放料结束不等待打印加工完成，下一次取料才检查ProcessDone。

Pick/Place完整返回后状态机更新设备/天车工件引用，充退磁脉冲及异常分类见[应用层设计](../应用层设计.md)。

## 5. 握手与展示边界

打号机的`ClearHandshakeAsync`复用统一`HandshakeReset`，仅将`LoadDone`（0005/PDU4）和`UnloadDone`（0006/PDU5）按FC06逐点写0；不清打印内容、内外径或四个PLC只读输入。作为源时，完整取料写`UnloadDone=1`后先移动到目标上方，再清这两点，清理返回后才释放源预约；作为目标时，开始放料前清上一轮两点残留，随后按原流程下发打印参数、放料结束写`LoadDone=1`。不增加放料结束立即清零，也不在异常Abort里新增PLC写入。

清理成功在`statemachine.txt`记录“握手位复位2/2：LoadDone、UnloadDone”；单点写失败记Warning并继续下一点，取消异常仍向状态机传播，沿用现有异常策略。日志成功数反映调用结果，不代表已经读回验证。

手动页清握手下拉当前仍仅列双头镗、斜床、研磨机，本次自动中转复位未扩展下拉列表。后台快照仍仅含四个输入，不读输出握手、直径或打印文字。
