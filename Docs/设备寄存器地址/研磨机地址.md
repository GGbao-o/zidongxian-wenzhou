# 研磨机点位与交互

核对日期：2026-10-08。源码：[GrinderMachineAddress](../../src/AutomatedLine.Infrastructure/Communication/GrinderMachineAddress.cs)、[DeviceModbusMaps.Grinder](../../src/AutomatedLine.Infrastructure/Drivers/DeviceModbusMaps.cs)、[GrinderHandler](../../src/AutomatedLine.Application/Transfer/Handlers/GrinderHandler.cs)。

## 1. 通信

新代研磨机，Modbus TCP固定端口502；站号取IP最后一段（192.168.2.90→90），无法解析为byte时兜底1。PDU地址=R编号×2+1，表中为0基地址。

输入FC03单Word逐点读，输出/参数FC06单Word写。除RunState数值外输入按非零true；输出握手写1，复位写0。

## 2. 后台读取输入

| 点名 | R编号 | PDU地址 | 含义 |
|---|---:|---:|---|
| RequestData | 7301 | 14603 | 请求数据 |
| RequestLoad | 7302 | 14605 | 请求上料 |
| LoadLockDone | 7303 | 14607 | 锁紧完成，上料车可退出 |
| RequestUnload | 7304 | 14609 | 请求下料 |
| UnloadReleaseDone | 7305 | 14611 | 松开完成，下料车可退出 |
| Machining | 7306 | 14613 | 0加工完成，1加工中 |
| SafetyDoor | 7307 | 14615 | 0关，1开 |
| RunState | 7308 | 14617 | 数字：0空闲、1忙碌、2报警 |

DeviceHandshakeRules在候选生成中排除RunState=2。卡面“加工中”来自内存工件，并非本表Machining；RunState=2也不单独使设备卡红框。

## 3. 输出握手与参数

| 点名 | R编号 | PDU地址 | 内容 |
|---|---:|---:|---|
| DataTransDone | 7311 | 14623 | 参数传输完成，1 |
| LoadInPlace | 7312 | 14625 | 上料到锁紧位置，1 |
| LoadDone | 7313 | 14627 | 上料结束，1 |
| UnloadInPlace | 7314 | 14629 | 下料到松开位置，1 |
| UnloadDone | 7315 | 14631 | 下料结束，1 |
| RollerDiameter | 7316 | 14633 | 工件直径，倍率1 |
| MachiningMode | 7317 | 14635 | 堵孔100→1大孔，其余→2小孔 |
| RollerLength | 7318 | 14637 | 工件长度，倍率1 |

参数Math.Round转ushort，不是双头镗的×100。自动写参数顺序为直径、长度、模式。研磨模式独立于工件LatheMachiningMode。

## 4. 实际流程

**取料**：RequestUnload=1 → 源XY/SafeZ → Z下降 → 等500ms单读X11 → 标志置true/充磁 → UnloadInPlace=1 → 等UnloadReleaseDone=1 → Z升 → UnloadDone=1。

**放料**：RequestData=1 → 写三参数 → DataTransDone=1 → RequestLoad=1 → Z下降 → LoadInPlace=1 → 等LoadLockDone=1 → 退磁 → Z升 → LoadDone=1。

不能将等待松開移到充磁前，也不能将退磁移到锁紧完成前；以上顺序由当前handler确定。完整Pick/Place成功后状态机才更新工件内存交接。

## 5. 清握手与大屏

自动中转/手动清握手都写0复位五个输出握手，参数不清。逐点失败记警告，不保证全部成功。大屏悬浮只展示八个输入，不读回本表输出/参数；显示顺序按英文键排序，详见[大屏文档](../页面布局/大屏展示页面.md)。
