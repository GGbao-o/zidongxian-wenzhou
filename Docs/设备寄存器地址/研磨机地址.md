# 新代研磨机寄存器地址

modbustcp通信协议 ip用数据库的ip  端口号502写死

**unitId = IP 末段**（如 192.168.2.90 → 90) 这个是站号 

### 地址转换

Modbus 地址 = R 编号 × 2 + 1。例：R7301 → 14603。

### 输入信号（机床 → 上位机，读）

| R编号 | Modbus 地址 | 信号名称         | 值说明                       |
| :---: | ----------- | ---------------- | ---------------------------- |
| R7301 | 14603       | 请求数据         | 0=关闭，1=请求数据           |
| R7302 | 14605       | 请求上料         | 0=关闭，1=请求上料           |
| R7303 | 14607       | 锁紧完成上料退出 | 0=关闭，1=锁紧完成           |
| R7304 | 14609       | 请求下料         | 0=关闭，1=请求下料           |
| R7305 | 14611       | 松开完成下料退出 | 0=关闭，1=松开完成           |
| R7306 | 14613       | 加工中           | 0=加工完成，1=加工中         |
| R7307 | 14615       | 安全门状态       | 0=门关闭，1=门打开           |
| R7308 | 14617       | 设备运行状态     | 0=空闲，1=忙碌中，2=机床报警 |

### 输出信号（上位机 → 机床，写）

| R编号 | Modbus 地址 | 信号名称         | 写入方式       |
| :---: | ----------- | ---------------- | -------------- |
| R7311 | 14623       | 数据传输完成     | 写1            |
| R7312 | 14625       | 上料到达锁紧位置 | 写1            |
| R7313 | 14627       | 上料完成         | 写1            |
| R7314 | 14629       | 下料到达松开位置 | 写1            |
| R7315 | 14631       | 下料完成         | 写1            |
| R7316 | 14633       | 版辊直径         | Word，mm       |
| R7317 | 14635       | 版辊加工模式     | 1=大孔，2=小孔 |
| R7318 | 14637       | 版辊长度         | Word，mm       |







# 天车与研磨机交互逻辑



上料交互：

1. 天车到研磨机上方 xy到位：读**请求数据=1**
2. 读到了 下发版辊直径 长度 加工模式  并且发**数据传输完成=1**
3. 下发完成读**请求上料=1**
4. 读到请求上料=1 天车z到位
5. z到位后 下发**上料到达锁紧位置=1**
6. 发完读锁紧完成**上料退出=1**
7. 读到后 天车放磁z回升安全位置 下发**上料完成=1**





下料交互

1. 天车到研磨机上方xy **读请求下料=1**
2. z到位 充磁 并且感应到有板信号
3. **发下料到达松开位置=1**
4. **一直读松开完成下料退出=1**
5. 读到后，z回升安全位置  **发下料完成=1**   然后天车去下一步操作
