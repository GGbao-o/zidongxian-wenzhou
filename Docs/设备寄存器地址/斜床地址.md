# 斜床宏变量与交互

核对日期：2026-10-19。源码：[LatheMacroAddress](../../src/AutomatedLine.Infrastructure/Communication/LatheMacroAddress.cs)、[LatheFocasDriver](../../src/AutomatedLine.Infrastructure/Drivers/LatheFocasDriver.cs)、[LatheHandler](../../src/AutomatedLine.Application/Transfer/Handlers/LatheHandler.cs)、[LatheYOffset](../../src/AutomatedLine.Application/Transfer/LatheYOffset.cs)。

## 1. 通信与后台快照

FANUC FOCAS，IP来自数据库，固定8193，无Modbus站号；cnc_rdmacro/cnc_wrmacro在每通道专用线程串行执行。当前后台固定读十个宏，按绝对值>0.01转true。

Application层DeviceStateCollector经LatheFocasDriver后台采集斜床状态，本轮连接/读取失败发布断开、Bad、空点表，下轮继续尝试。EW_SOCKET(-16)后在同一专用线程释放失效句柄并清连接标志，本次异常仍向上传播；下一轮采集/下一次请求自动尝试重建连接，网络/CNC服务可用且整批读取成功才恢复状态。本次写宏不自动重发，失败批次不继续读剩余宏，避免通信不确定时重复下发握手。端口、3秒连接/操作超时和采集周期不变，详见[通信说明](../通信与点位说明.md#3-focas-通道)。

| 宏 | 点名 | 方向 | 含义 |
|---:|---|---|---|
| #1001 | RequestData | 机床→上位机 | 请求数据 |
| #1002 | RequestLoad | 机床→上位机 | 请求上料 |
| #1003 | TailstockClamped | 机床→上位机 | 尾座夹紧到位 |
| #1004 | RequestUnload | 机床→上位机 | 请求下料 |
| #1005 | TailstockOpened | 机床→上位机 | 尾座分开到位 |
| #1101 | DataSentDone | 上位机→机床，读回 | 数据下发完成 |
| #1102 | CraneLoadInPlace | 上位机→机床，读回 | 天车上料到位 |
| #1103 | CraneLoadDone | 上位机→机床，读回 | 天车上料完成 |
| #1104 | CraneUnloadInPlace | 上位机→机床，读回 | 天车下料到位 |
| #1105 | CraneUnloadDone | 上位机→机床，读回 | 天车下料完成 |

五个输出也是大屏可见的读回点；其余设备Modbus输出通常不采集，不可将这两类混淆。设备等待使用上述后台快照，不在每次条件判断直接调SDK。

## 2. 加工参数写入

| 宏 | 写点名 | 来源/格式 |
|---:|---|---|
| #800 | RollerLength | 工件Length，double，原值mm |
| #801 | RollerDiameter | 工件Diameter，double，原值mm |
| #802 | BorePlug | 工件PlugHole，70/100 |
| #909 | MachiningMode | 工件LatheMachiningMode，UI输入0～10，原值 |
| #651 | TailstockStop | 驱动支持写点名；当前正常handler未调用 |

不按ModbusWord或×100处理。#909并非固定1/2/3，也不是按堵孔自动生成。

这些地址存在于常量类，但ReadAllSignalsAsync未加入快照；当前大屏不显示、候选及handler不等待它们。不能将地址表所有常量当作已实现采集。

## 4. Y二次偏移与Z取放位

每台按App.Transfer.Lathes[设备Id]配置顶尖距离、大孔/小孔偏移：

`YOffset=Round((TailstockCenterDistance-Length)/2+孔径偏移, AwayFromZero)`。

PlugHole=100用BigHoleOffset，其他用SmallHoleOffset；默认122/55。缺少该设备配置时handler返回0。顶尖距离默认0，需要现场标定。

基础XYZ=设备XYZ+天车OffsetXYZ；斜床`ZDrop=Round((Diameter/2)/0.9537)`，取料与放料的编码器绝对目标均为`Round(基础Z-ZDrop)`。例如直径103.1、设备Z=2000、天车OffsetZ=30时，补偿54、目标Z=1976。Y二次偏移不改变Z公式。SafeZ为车绝对配置，不加偏移。

## 5. 取料顺序

1. 等#1004 RequestUnload。
2. 到 `(基础X,基础Y-YOffset,SafeZ)`，下降到Z取放。
3. 等500ms专用读天车X11；无板按配置仅Z有限补降，不改变pickY，成功有板后才置取料充磁标志、调用充磁。
4. 写#1104=1，等#1005尾座张开。
5. 相对Y移动+YOffset回中心。
6. 移到基础XY/SafeZ，写#1105=1。
7. Pick返回后状态机清源引用，车持有工件。

补降默认追加3次×5mm，每次成功后等500ms重查，最多4次专用读取、15mm累计指令下降；尚未写#1104，耗尽/读取或运动失败仍按充磁前保留工件。参数、次数及实际坐标日志见[应用层说明](../应用层设计.md#541-取料无板的有限补降与日志)。

## 6. 放料顺序

1. 等#1001，写#800/#801/#802/#909，写#1101=1。
2. 等#1002，在基础XY下降到Z取放。
3. 相对Y移动-YOffset，写#1102=1。
4. 等#1003夹紧，退磁并单读X7。
5. 绝对移动到`(基础X,基础Y-YOffset,SafeZ)`，保持已经对接的二次偏移Y回升，本阶段不返回中心Y。
6. 写#1103=1；Place返回后交接内存并将工序改Lathing。

## 7. 握手复位

中转到目标上方时，对源/目标分别调用handler，将#1101～#1105写0。手动页可补清同五点。只清输出握手，不清#800等参数或#651；逐点失败记警告继续。故障Abort不执行宏写入。

完整工艺与异常分流见[应用层设计](../应用层设计.md)。
