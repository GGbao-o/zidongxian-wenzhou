## 加工参数写入地址

| 数据项        | R地址 | Modbus地址 | 格式           | 写入规则     |
| ------------- | ----- | ---------: | -------------- | ------------ |
| 长度          | R2041 |       4083 | 16位无符号整数 | 是多少就多少 |
| 直径          | R2043 |       4087 | int            | 值 * 100     |
| 左堵厚        | R2044 |       4089 | int            | 值 * 100     |
| 右堵厚        | R2045 |       4091 | int            | 值 * 100     |
| 内孔锥度      | R2046 |       4093 | 16位整数       | 值*100写入   |
| 内孔成活/版孔 | R2047 |       4095 | int            | 值 * 100     |
| 圆角大小      | R2048 |       4097 | 16位整数       | 值*100写入   |

| R6102 |      12205 | 上位机→双头镗 | 数据下发完成写1； |
| R6103 |      12207 | 双头镗→上位机 | 请求上料，        |
| R6104 |      12209 | 上位机→双头镗 | 上料完成写1；     |
| R6107 |      12215 | 双头镗→上位机 | 请求下料，        |
| R6108 |      12217 | 上位机→双头镗 | 下料完成写1       |
